# SentinelX One-Folder Copy

This directory is a flat collection of all SentinelX source files.

Original folder paths are encoded with `__` in filenames. For example:

- `backend/app/main.py` → `backend__app__main.py`
- `frontend/app.js` → `frontend__app.js`
- `public/manus-routes.json` → `public__manus-routes.json`
- `tests/test_smoke.py` → `tests__test_smoke.py`

The runnable project with its original folder structure remains available separately in `SentinelX_Full`.
